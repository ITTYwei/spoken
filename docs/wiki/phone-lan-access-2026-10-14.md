2026-10-14 当前开发地址：`http://192.168.20.41:8091`。

- 电脑 WLAN：192.168.20.41，IDEA 后端监听 8091，可接受局域网请求。
- 手机 WLAN：192.168.20.54，与电脑同在 192.168.20.0/24 网段。
- Android 默认地址已更新，并构建、安装新的 debug APK。
- 手机 DataStore 已保存同一局域网地址，保留设备号和账号存储；原连接配置备份在忽略的 target 测试目录。

验证：电脑经局域网地址访问健康接口成功；手机直接通过 Wi-Fi 请求 `/actuator/health` 返回 HTTP 200 和 UP；修改后再次验证成功，应用已重新打开。尚未替用户重新登录和建立新的数字人媒体会话。

手机和电脑需连接可互通的同一局域网。电脑 Wi-Fi 地址由 DHCP 分配，网络变化后应重新确认地址；已有设备的保存地址优先于代码默认值。

登录凭证绑定服务器来源。由旧回环地址切换到局域网地址后，应用按现有隔离规则可能要求重新登录，账号与后端数据不变，不跨来源自动转移令牌。

Windows 现有规则中存在公用网络 Java 阻止项；尝试添加仅限本局域网的端口规则时，当前进程没有管理员权限，因此没有修改防火墙。实际手机健康访问已经成功，本次无需新增规则或关闭防火墙。
