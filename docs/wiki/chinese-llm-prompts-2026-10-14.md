# 自有 LLM 提示词中文化（2026-10-14）

## 修改范围与边界

用户要求后端自有提示词采用中文，随后明确“框架的代码就不要改了，只改跟我们自己写的”。

- 主教练 YAML 的描述和指令、六档本轮教学规则、原话与上一任务说明采用中文。
- 课程模式、继续选择状态、教材数据标题与本项目辅助陪练指导采用中文。
- 历史引用边界与练习素材说明、后台能力证据观察、字幕翻译指令采用中文。
- 八个业务工具的调用条件、拒绝条件与参数说明采用中文。
- 保留英文教材原题、用户原话、跟读目标、工具名称、字段名、枚举值和占位符。
- 普通聊天静默维护明确事实，跟读禁用业务工具，仍遵循已有程序校验。

不改 ADK 身份模板、SDK 或脚手架示例 Agent。最初试加的 `AdkPromptLocalizer` 已撤销，模型转换链没有身份翻译步骤。自有教学预算检测同步识别中文数据边界，防止改名后跳过实际容量校验。

数据库历史迁移中的英文官方人设不修改：当前 ScenarioVO 已清除 free/interview 的旧人设，不会发送给模型；用户提供的文本和第三方数据不自动翻译。

## 验证

`spoken-server-app/target/chinese-prompt-tests.log`：91 项检查通过，覆盖教学动作、六档策略、跟读隔离、静默事实维护、工具身份与去重、字幕翻译、历史裁剪及上下文预算。

`spoken-server-app/target/chinese-prompt-live-tools.log`：另 9 项检查通过，包含开场回归及当前配置模型的在线验收。模型通过现有脚手架完成三轮真实工具调用：切换指定课程、切回自由对话、保存明确要求记住的长期目标；持久化使用隔离替身，不修改用户设置。合计 100 项检查通过。

中文规则与完整课程按现有 12000 字节配置通过六档语音上下文检查；课程原题完整保留。超预算的实际模型请求仍在调用前拒绝。

## 加载与体验

需要在本地 IDEA 重启后端，让 YAML 配置和 Java 类重新加载。手机仍使用原有 IDEA 连接；本次未修改 Android，也未操作正在进行的手机对话。提示词采用中文不等于数字人全部说中文，回复语言继续由六档教学策略决定。
