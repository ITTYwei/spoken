# 手动选择英语陪练档位

入口：数字人页面左上角 → 水平、偏好与账号 → 英语水平 → 练习档位 → 调整。

选择 L1–L6 或自动适配，点击保存。能力描述仍根据真实练习更新；手动选择只控制陪练语言难度，不改写能力评估，不清空证据。

| 选择 | 陪练难度参考 |
|---|---|
| 自动适配 | 沿用基于真实练习的稳定档位，新用户默认 L2 |
| L1 | 单词与短语，中文支持 |
| L2 | 日常短句，中文支持 |
| L3 | 简单日常交流 |
| L4 | 连续表达日常想法 |
| L5 | 自然交流与经历描述 |
| L6 | 观点表达与复杂话题 |

## 生效与数据流

保存后从下一次新建对话生效，已有对话保持冻结档位。新会话初始化先读取手动选择，存在时使用该档位，不运行自动提升；恢复自动后，沿用原稳定档位与证据流程。

手机设置页 → REST → LearnerLevelCase 获取可信登录主体 → LearnerProgressService 校验/保存 → LearnerProgressRepository → Mapper。Controller 不接收 userId；Case 协调账户身份和学习者领域，Domain 不访问其他领域仓储。

新增迁移 V17 在 learner_profile 添加 nullable manual_english_level，null 表示自动；原 english_level、升级时间与能力证据不变。手动值不能由后台观察覆盖，账号之间独立保存。

- GET /api/v1/me/english-level：返回 automaticLevel、manualLevel、effectiveLevel。
- PUT /api/v1/me/english-level：请求 {"level":"L4"} 保存；{"level":null} 或空对象恢复自动。
- 只接受 L1–L6，非法码返回参数错误；未登录拒绝访问。

返回真实保存快照，手机不乐观伪造成功；旧账号请求的迟到结果不更新新账号页面。旧后端尚未升级时显示“练习档位未加载 / 重试”，不会阻塞伙伴及其他设置的加载。
