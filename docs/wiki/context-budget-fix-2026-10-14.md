# 语音对话无回复：上下文预算修复

## 实际故障

用户真机课程对话在 2026-10-14 15:33 与 15:35 的语音回合完成识别和评测后，TeachingPreparation 调用 ChatContextService 抛出 `current_turn_context_too_large`。模型尚未生成回复，所以后续收到没有正文的播报结束事件。日志也有独立 `no_speech` 记录，不能把这两个原因混为一谈。

原发布配置采用保守 UTF-8 字节预算 6000；必需教学策略、当前状态、课程内容与 2500 静态指令预留合计超过容量。原测试的短输入/无实际人设组合未覆盖该边界。

## 修改

- ChatContextService 默认值与 application-dev 发布配置统一为 12000 字节。
- 必要上下文超限时仅记录会话和容量组成，不打印用户原话、记忆或身份凭证。
- 仍保留完整课程与本轮状态；可选历史按剩余容量裁剪，超大课程拒绝机制不变。
- 新测试加载实际发布预算，覆盖六级语音教学策略、中文人设、前题任务和完整日常居家题组。

## 验证与生效范围

59 项相关回归通过，包含语音 Case、教学规则、记忆裁剪和 Agent 课程链路；测试日志为 `spoken-server-app/target/context-budget-fix-tests.log`。已重新打包并更新本任务本机 8092 服务，原 8091 服务保持。本次不需要重装 Android。

服务重启前的运行中会话失效，手机需重新进入数字人建立新会话。构建和上下文修复已验证，不把用户尚未重新发起的自然语音体验记作已通过。
