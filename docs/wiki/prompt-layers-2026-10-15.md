# 主教练提示词分层与英语范围

## 本次行为

自由聊天也仅限英语学习与口语练习。英文日常交流可作为口语练习，中文日常话题可引导为英文表达；编程、业务咨询等无关请求简短说明范围并引导回英语，不展开解答。与练习有关的选课、数字人、音色、档位和偏好管理仍可正常调用既有业务工具。

## 消息结构

SYSTEM 经原脚手架的 turn_policy 入口注入，顺序为 system_rules（稳定规则）与 level_policy（可信等级）。等级只决定表达难度，不决定用户要学习什么。L1/L2 的英文后附中文含义，知识讲解可用易懂中文，允许国际音标。固定示例不代表所有等级都使用同样语言。

USER 仍先放可裁剪的历史/记忆，再放不可裁剪的当前数据：

```text
<session_context>
{跟读证据、教学建议、上轮结果、已播目标、人设、学习请求与当前课程背景}
</session_context>
<user_input>
"本轮实际原话"
</user_input>
```

字段由 JSON 编码，额外转义 <、>、&；例如用户说出结束标签也不会关闭外层块。它用于隔离数据边界，不替代工具鉴权或业务规则。

教学动作和结果码只在元数据中，不再拼成 SYSTEM 的本轮命令；模式用中文背景描述，版本和最近课内部编号不再交给主对话提示词。可信工具上下文仍照旧传递真实版本与主体，权限不依赖模型读到的字段。

原话在英语范围和系统边界内优先于旧任务、历史和教学建议。真实跟读问句只是素材，不回答其问题、不写入个人偏好；如果用户在跟读途中问“这句什么意思”或提出新学习需求，则先回答。建议不强制执行；有可靠证据才温和纠音。

“我想学音标”保留为本场学习背景；下一轮“能举例吗”可继续关联。新请求覆盖旧需求，学习请求与完整课程仍在 required 上下文中，不依赖模型记忆，也不会随历史被裁掉。

## 实现边界

ReplyPromptBuilder 负责纯文本分层与编码；TeachingPreparation 只通过领域服务读取课程和教学背景；ADK、Runner、模型客户端和框架适配代码均未修改。生产 spoken-server.yml 同步范围、元数据和参考策略准则；模型参数、结构化输出和播报协议不变。
