# 教学结果枚举

> 最新实现：教学策略只作参考，知识请求由模型理解，删除强制关键词分流与等级抽样；本次学习请求原话每轮必保留。以下早期流程以 [教学参考与学习目标](teaching-advisory-learning-request-2026-10-14.md) 为准。


`TeachingDecisionVO.outcome` 已从字符串改为 `TeachingOutcomeEnum`。内部判断使用枚举比较与穷尽 switch，新增结果时必须补齐提示词分支；数据库、JSON 与提示词仍显式使用原有文本码。

## 每项处理什么

| 枚举 | 触发条件 | 后续处理 |
|---|---|---|
| ENGLISH_QUESTION | 明确询问词义、语法、翻译、表达或发音方法 | EXPLAIN 直接解答并按需举例，不强制跟读、纠音或练习追问 |
| RESPONDED | 普通有效回应 | 接住实际内容，执行一个相关追问或跟读示范；独立回答仍需额外观察条件 |
| DECLINED | 明确拒绝当前任务 | 接受选择、放下旧任务，不作为能力差的证据 |
| HELP | 请求理解或表达帮助 | 解释上一句、简化问题或目标，保持一个任务，不改稳定等级 |
| NO_AUDIO | 教学规则收到空白输入 | 邀请简单回应，不推断拒绝、零分或发音问题 |
| READ_NOT_ATTEMPTED | 有待跟读任务，但话语不像该目标 | 按本轮真实意图回应，不对照旧目标纠音 |
| READ_UNCERTAIN | 评测合法但不足以通过/具体指导，或重试到上限 | 离开旧目标，不编造错词，转向简单新问题 |
| NO_EVIDENCE | 评测缺失、分数非有限或越界等 | 不猜发音，保留练习输入性质并继续交流 |
| READ_PASS | 目标跟读评测有效、总分达标且无可信目标词问题 | 结束跟读，安排下一步；本轮仍不能当作用户向教练提问或真实偏好 |
| READ_RETRY | 有可信目标词发音差异且未达重试上限 | 原样示范、共建语气指导一个细节、再邀请跟读；整体高分不掩盖具体证据 |

每项都有中文常量注释、description 和 handling。code 是稳定协议值；未知码严格拒绝，不默认映射为 RESPONDED 或 NO_EVIDENCE。

## 边界

- 教学结果说明“本轮如何回应上一任务”；下一任务仍由 TeachingTaskVO 管理，二者不能混用。
- 同名 HELP / DECLINED 出现在 Agent 能力观察协议时属于其他领域的结果，不直接复用此枚举。
- Jackson 使用 code 序列化，TeachingReplyRepository 显式转 code 后入库，不使用枚举 ordinal，不需数据库迁移。
- 自有教学策略、提示词、Case 和相关测试已替换结果魔法字符串；框架装配没有修改。

## 验证

回归检查包括所有结果的 JSON 和决策对象往返、仓储原文本码、未知值拒绝，以及既有教学、播报、语音入口和 Agent 操作规则。

本轮 72 项回归检查通过；另外 8 项兼容/数据库检查通过，包含随机临时库中的真实 MyBatis 写入和历史召回。既有文本码未变化，不需要数据库迁移。IDEA 后端重启后加载类型重构。
