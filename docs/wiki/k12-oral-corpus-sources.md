# K12 / 青少年英语口语 —— 教学课本与语料来源清单

> **用途**：为 `spoken-server` 扩充 **K12 / 青少年** 方向的口语场景与对话语料。
> **定位**：这是一份「选材地图」，不是书单推荐。判断标准只有一条 —— **能不能拆成产品能用的场景卡与对话脚本**。
> 建立时间：2026-10-13。选材结论或授权政策变化时同步本页。

---

## 0. 结论速览

按「语料可用性」排序，四类来源各有分工，最佳做法是**组合使用**：

| 类别 | 代表 | 拿它做什么 | 版权姿态 |
|---|---|---|---|
| **① 国家课标（骨架）** | 义务教育英语课程标准（2022 年版） | 当**场景分类树**：三大范畴 → 主题群 → 子主题，直接就是话题库目录 | 公开文件，可直接用 |
| **② 国内主流教材（话题）** | 人教版 PEP / 外研社 / 译林牛津 | 提供**最贴中国学生生活**的话题与单元结构 | 仅作话题与结构参考，文本需改写 |
| **③ 国际原版教材（对话）** | Let's Go / Kid's Box / Super Minds / Side by Side | 提供**成段的对话脚本与句型框架**，做对话语料最省力 | 商用需授权；结构可仿写 |
| **④ 考试导向语料（题型）** | 中考听说机考 / 高考听说 | 题型本身天然就是**产品场景**（朗读、情景问答、话题简述） | 真题受保护；题型与话题可借鉴 |

> 一句话：**用①搭目录、②定话题、③造对话、④定题型**。四者叠加，就是一套完整的产品场景语料流水线。

## 1. 选材标准（为什么是这些）

做**口语产品语料**和做**教材推荐**是两件事。候选来源要同时满足：

1. **对话密度高** —— 有成句的 `dialogs`，而不是只有单词表 / 图片。只有对话才能拆出「人设 + 开场白 + 追问线」。
2. **话题可拆成场景卡** —— 一个话题能否落成：`人设(systemPromptHint) + 开场白(按档位×3) + 3~6 条目标表达 + 追问方向`。
3. **贴近中国 K12 学生生活** —— 文化不隔阂，学生才愿意开口（原版教材常有的"生日派对/夏令营"对中国孩子是隔的，需要本土化）。
4. **有分级依据** —— 能对应到年龄 / 学段 / CEFR，才能映射到产品的 `LOW / MID / HIGH` 档位。
5. **可合规使用** —— 商用要授权，或退一步只借结构与话题、自己改写文本。

## 2. 骨架来源：2022 版课标（免费、可作场景分类树）

《义务教育英语课程标准（2022 年版）》是**公开的国家标准**，可直接作为场景分类的目录骨架。它以**三大主题范畴**组织内容，下设主题群与子主题：

| 范畴 | 主题群 | 子主题举例（一~三级拼接） |
|---|---|---|
| **人与自我** | 生活与学习 / 做人与做事 | 身边事物与环境、时间管理、个人喜好与情感、家庭与家庭生活、学校生活与个人感受、饮食与健康、自我管理、情绪调节、零用钱与合理消费、劳动习惯 |
| **人与社会** | 社会服务与人际沟通 / 文学艺术与体育 / 历史文化与社会 / 科学与技术 | 班级与学校规则、团队活动与集体生活、同伴交往与相互尊重、运动与健康、交通与安全、常见职业、中外节假日与文化体验、跨文化沟通、科学技术改变生活 |
| **人与自然** | 自然生态 / 环境保护 / 灾害防范 / 宇宙探索 | 天气与日常、四季与生活、身边的自然现象、常见动物、家乡与世界的地理与自然、绿色生活、自然灾害与自我保护 |

> **为什么先从这里开始**：课标主题群 = 免费、权威、且被中国 K12 教学与考试普遍认领的**话题坐标**。产品的场景 id、话题标签、档位难度都可以挂在这棵树上，学生（和家长）一眼能对上"我们课本里学过"。

## 3. 国内主流教材（话题最贴中国学生）

| 系列 | 出版社 | 学段 | 话题特点 / 对语料的价值 |
|---|---|---|---|
| **人教版 PEP（三年级起点）+ Go for it!（初中）** | 人民教育出版社 | 小学~初中 | 全国使用面最广。单元话题规整、贴近校园与家庭生活，是**中文母语学习者语料的第一参照** |
| **外研社 新标准 / 新版初中** | 外语教学与研究出版社 | 小学~初中 | 新版单元以"话题为纲、功能为目、任务型活动为主线"，**任务型设计天然适合改成对话场景** |
| **译林牛津版** | 译林出版社 | 小学~初中（江苏） | 与江苏中考听说机考**直接对应**（朗读短文、话题简述都出自这套教材） |
| **人教版 / 外研社 高中必修+选择性必修** | 人教 / 外研社 | 高中 | 话题更抽象（科技、文化、社会议题），适合高中段与高考听说 |

## 4. 国际原版教材（对话脚本最丰富，做对话语料的捷径）

| 系列 | 出版社 | 适用年龄 | CEFR / 级别 | 对话与场景特点 |
|---|---|---|---|---|
| **Let's Go**（5th ed.） | 牛津 | 大班~小学 | Pre A1–B1 | **口语启蒙经典，对话密度最高**，课堂活动大量成对对话，最适合抽成对话语料 |
| **Kid's Box** | 剑桥 | 4–10 岁 | Pre A1–A2 | 零基础友好，听说技能突出，游戏/歌曲多，**场景贴近儿童日常** |
| **Super Minds** | 剑桥 | 6–12 岁 | Pre A1–B1 | 对话/故事结合 CLIL 与思维训练，故事性对话质量高，难度略高于 Kid's Box |
| **Family and Friends** | 牛津 | 零基础~小学 | Pre A1–B2.1 | 语言+情感社教结合，故事线清晰，适合做"有情节"的场景 |
| **Power Up** | 剑桥 | 6–12 岁 | A1–B1 | 生活化场景，把 KET/PET 考点融进日常对话，衔接考级 |
| **Our World / Look** | 国家地理学习 | 6–12 岁 | Pre A1–B1 | 真实图片+真实小故事，**话题广度大**，适合"世界文化"类场景 |
| **Side by Side** | 培生 | 青少年~成人 | A1–B2 | **语法+交际双主线**，对话模板化程度高，最容易被"拆成句型+场景" |
| **THiNK / Unlock** | 剑桥 | 10–18 岁 | A1–C1 | 话题深、偏批判性思维与学术，适合高中段与"观点表达"场景 |
| **新概念英语（1–2 册）** | 培生 | —— | A1–B1 | 语料偏旧，与新课标话题贴合度一般，**不优先推荐做 K12 语料** |

> **实用建议**：`Let's Go` + `Side by Side` 是做**对话脚本**性价比最高的两套 —— 前者对话最自然、后者句型最规整，配合一套国内教材（话题本土化）即可。

## 5. 考试导向语料（题型 = 现成的产品场景）

K12 口语机考题型与产品场景**高度同构**，是最省力的场景来源：

| 题型（各地机考） | 产品对应场景 | 说明 |
|---|---|---|
| **朗读短文**（读一篇教材短文） | **跟读 / 朗读**场景 | 与产品现有「跟读」开关 + `expectedText` 参照题面**直接对应**（见 `product-design.md` §6.3） |
| **情景问答 / 听对话作答** | **情景对话**场景 | 给定情景（问路、购物、就医）多轮问答 |
| **话题简述 / 听后转述** | **话题陈述**场景 | 给定话题，学生连续说≥7句；对应产品的"话题引导"型数字人 |
| **回答提问（听后回答）** | **面试/问答**场景 | 与现有 `interview` 场景同构，可直接复用 |

**已知的具体范围（可作话题清单）**：

- **江苏中考（译林版）**：朗读短文 18 篇 + 话题简述 12 个话题，均出自译林教材；2025 起话题简述**取消中文提示与范文**，只给话题（如 `My favourite sport`、`Teenage problems`、`A DIY story`），要求学生自组织语言。
- **北京中考听说机考**：听后选择 / 听后回答 / 听后转述 / 短文朗读；常考话题方向 —— 日常交流（问路、感谢、问候、打电话）、生活需求（请求建议、健康就医、购物、旅游计划）、日常闲聊（天气、兴趣、时间、职业）、社交礼仪（祝愿、就餐、学校生活、恭维应答）。
- **广东高考听说**：模仿朗读、角色扮演（三问五答）、故事复述。

> **合规提示**：真题文本通常受保护，**题型结构 + 话题清单可以借鉴，题目原文不要直接搬**。

## 7. 版权与合规红线（务必先过这一关）

1. **教材文本受版权保护** —— 剑桥、牛津、国家地理、人教/外研/译林 的课文与对话**不能整段搬运**进产品、数据库或提示词。合规做法：**借话题与结构，自己改写对话**。
2. **商用需授权** —— 若要在产品中直接使用某套教材的文本/音频，需与出版社谈授权（剑桥、牛津、国地理 均有 ELT 版权部门）。
3. **可放心用的** —— 国家课标、考纲、题型说明属公开文件；分级读物的**免费在线**资源可作个人/非商用参考，商用仍需授权。
4. **K12 特有红线**：
   - 未成年人个人信息最小化，不诱导填写真实姓名/学校/联系方式（考试本身也要求"避免出现真实个人信息"）。
   - 话题避开成人、敏感、消费诱导内容；价值观导向需正向。
   - **与产品红线联动**：K12 家长天然想看"报告/分数"，但产品「不做错题本、不报分」的红线（`product-design.md` §1.2）在 K12 场景下更要守住 —— 一旦变成"给家长看孩子的等级"，就回到了考试语境。

## 8. 落到本项目的映射（建议场景卡）

产品里一个场景 = `systemPromptHint + openingLine(按档位×3) + voice + level`。下面是按 K12 话题可直接开工的候选（沿用现有 `InMemoryScenarioRepository` 的写法，将来迁到 `conversation_scenario` 表）：

| 建议 scenario id | 话题来源 | 人设要点（systemPromptHint） | 建议 level | 追问方向 |
|---|---|---|---|---|
| `school-day` | 译林八上 School life / 人教 School life | 「同桌/学长」—— 同龄、好奇、爱聊校园日常 | beginner | 最喜欢的课 → 为什么 → 老师怎样 → 课间做什么 |
| `hobby-club` | 人教 Hobbies / 译林 Outdoor fun | 「社团伙伴」—— 一起玩、互相分享兴趣 | beginner | 玩什么 → 和谁 → 什么时候开始的 → 下次一起？ |
| `food-order` | 外研 Food matters / 人教 Food and drink | 「餐厅服务员」—— 友好、耐心，帮助点餐 | beginner | 想吃什么 → 口味偏好 → 饮料 → 打包吗 |
| `travel-plan` | 外研 Hitting the road / 人教 Travel | 「旅行搭子」—— 一起规划周末/假期行程 | intermediate | 去哪 → 怎么去 → 和谁 → 几天 |
| `festival` | 译林 Let's celebrate! / 人教 Festivals | 「外国朋友」—— 对中国节日好奇，也分享本国节日 | intermediate | 你过什么节 → 怎么过 → 吃什么 → 和谁一起 |
| `read-aloud` | 考试朗读短文 / Oxford Owl 分级读物 | 不设人设，**朗读/跟读**用（走脚本轨，`expectedText` 参照） | 按读物分级 | —— |

**K12 场景的三条差异化注意事项**：

1. **按年龄段分人设**：小学段用"同龄小伙伴/温柔的大哥哥大姐姐"，初中段可加"有观点、会追问的同伴"。人设语气与用词要匹配年龄。
2. **分级语言策略要下移**：K12 主体的初始档位应更多落在 `LOW/MID`，`HIGH` 留给有一定基础的高年级；`opening_line_low` 的中文陪练设计在 K12 尤其重要（见 `product-design.md` §3.4）。
3. **话题选中性、可展示内容**：避免需要学生暴露真实个人信息的追问（家庭住址、学校名、联系方式），把追问引向"喜好、经历、看法"这类安全话题。

## 9. 建议落地步骤

1. **搭目录**：用课标三大范畴/主题群做场景分类树，标注每个子主题对应年龄段。
2. **产场景卡**：每个子主题产出 1 张场景卡（人设 + 开场白×3 档 + 3~6 条目标表达 + 追问线）。
3. **造对话**：从 `Let's Go` / `Side by Side` 的对话结构**仿写**，用国内教材话题**本土化**。
4. **接跟读素材**：用考试朗读短文 / Oxford Owl 分级读物做 `expectedText` 参照（先确认授权范围）。
5. **合规评审**：按第 7 节逐条过，尤其 K12 的未成年人信息与价值观红线。
