## 梳理「使用教材时提示词如何处理」链路

- 教材**不进系统提示词**，作为本轮必需数据每轮拼进 USER 消息的 CURRENT TURN 段：`TeachingPreparation.prompt:137-144` → buildManaged 之后追加 `CURRENT PRACTICE: <mode>; version=N` + `CHOICE AT CURRENT INPUT: pendingContinue/recentTextbook/recentLesson`，**仅 mode=COURSE** 再追加 `textbooks.lesson(book,lesson).context()`（= TextLessonVO.context()：`CURRENT TEXT LESSON DATA: title` / `Original questions` 全量 / `Project teaching guidance`）。
- 系统侧同步加约束：`TeachingPreparation.systemPolicy:151-156` = buildSystemPolicy(decision) + 三条 COURSE 规则（在原题范围内带练 / 一次只问一题 / 不得宣称分数或完成课程）→ `ChatService:206` 写入本轮短会话 state["turn_policy"] → spoken-server.yml `{turn_policy?}` 由 ADK 占位符注入 SYSTEM。
- 三道闸：①选课 `TextLessonVO.explicitlyReferenced`（aliases 匹配原话），不相关直接 reject；②`TextbookService.lesson:26` estimate(context)>1400 → lesson_too_large；③教材在 currentInstruction 内不参与 HybridReducer 裁剪，但 12000 - 2500 - systemPolicy 预算不足时 `ChatContextService:59` 抛 current_turn_context_too_large **整轮失败**。
- 旁路（模型工具轨）：queryPractice / selectPractice / continueRecentLesson → `AgentActionCase.switchPractice:77` 把同一段 lesson.context() 作为 lessonData 回灌模型。
- 风险点：教材每轮全量重复注入，token 随课增大；lesson.context() 仅用 title/questions/addedGuidance，objective 与 provenance 的 common_error/extend_move/probe 都未进提示词。
